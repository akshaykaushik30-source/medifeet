# MediFeet — Premium Orthopedic & Comfort Footwear

A modern, responsive e-commerce web application engineered to match the official **MediFeet** Figma design system with interactive video storytelling, biomechanical technology showcases, dynamic product filtering, and seamless cart management.

---

## ✨ Features

- **Interactive Community Story Carousel**:
  - Auto-advancing video slider with active progress bar and pause-on-hover.
  - Hover-to-play video preview across all community story cards.
  - High-definition official MediFeet Reels featuring Shilpa Shetty Kundra, Bobby Deol, and orthopedic comfort showcases.
  - Fullscreen video modal with unmuted audio playback.
- **Comfort Technology Interactive Showcase**:
  - Dynamic biomechanical sole breakdown with synced video tracks:
    - *Everyday Lifestyle Walk* (outdoor garden path test)
    - *Cloud Cushioning* (heel & midsole shock absorption test)
    - *All-Day Support* (anatomical arch bridge & spinal alignment)
    - *Adaptive Comfort* (plush contour memory foam)
  - Live demo switcher, sound toggle, and instant card hover previews.
- **Continuous Trust Marquee Divider**:
  - Infinitely scrolling green `#1E3F20` marquee banner featuring:
    - *Easy Exchange & Return*
    - *Secured Payment*
    - *24 x 7 Chatbot Support*
    - *Free Shipping*
    - *Cash on Delivery*
- **E-Commerce Catalog & Product Showcase**:
  - Category filtering (All, Men, Women, Ortho Comfort, Slippers).
  - Quick View modal with size selection (UK 6 – 11) and stock count.
  - Persistent shopping bag with slide-over drawer, quantity controls, and subtotal calculation.
  - Toast notification feedback on all user interactions.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Google Fonts (*Outfit*, *Geist*, *Geist Mono*)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/<YOUR_USERNAME>/<YOUR_REPO_NAME>.git
cd <YOUR_REPO_NAME>
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
The optimized build output will be generated in `dist/`.
